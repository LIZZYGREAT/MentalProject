## API 语义约束与复现

外部模型只输出难度、认知要求、重要性、时限、社会评价、不可控性等语义，不直接给压力分。规则是锚点，API 融合权重不超过 0.30，单维最终改变量不超过 0.12，明确高难词的规则下限不可被 API 降低。

固定提示词、规则、融合策略、模型名和规范化输入共同形成 SHA-256 指纹。有效 API 原始响应与最终融合值写入本地 SQLite；相同指纹重跑优先使用冻结缓存。完整规范见 `info/event_semantic_api_protocol.md`。

这组结果排除了明显刷屏与高负荷下完全静默。真实上线后仍须根据用户对“是否过多、是否及时、是否有帮助”的反馈校准阈值、持续时间和冷却时间。
